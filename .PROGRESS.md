## ⏳ Next Steps

### Database Setup (User Responsibility)
1. **Set up PostgreSQL:**
   - Install PostgreSQL locally if not running
   - Create database: `monk_ai`
   - Update `backend/.env.local` with real `DATABASE_URL`
   - Example: `DATABASE_URL="postgresql://user:password@localhost:5432/monk_ai"`

2. **Sync schema:**
   ```bash
   cd backend
   npx prisma db push
   ```

### Test Backend First
1. **Start backend:**
   ```bash
   cd backend
   npm run dev
   # Should show: "Monk.ai backend running on :3001"
   ```

2. **Verify routes with curl:**
   ```bash
   # Health check
   curl http://localhost:3001/health
   
   # Register user
   curl -X POST http://localhost:3001/api/auth/register \
     -H "Content-Type: application/json" \
     -d '{"email":"test@test.com","password":"pwd123","name":"Test"}'
   # Returns: {"token":"...", "user":{...}}
   
   # Get profile (use returned JWT)
   curl -H "Authorization: Bearer <token>" http://localhost:3001/api/user/profile
   ```

### Test Frontend (After Backend Running)
1. **Install dependencies:**
   ```bash
   cd frontend
   npm install
   ```

2. **Start frontend:**
   ```bash
   npm run dev
   ```
   - Opens LoginScreen (register/login)
   - Creates account → navigates to Onboarding
   - Personality selection (step 1) → Name → Identity
   - Saves to backend, redirects to main app

3. **Test full E2E:**
   - Register account
   - Personality selection + identity
   - Send message to coach (should call backend API)
   - Create habit, mark complete
   - Check-in (morning/evening)
   - Close browser, login again → data persists
